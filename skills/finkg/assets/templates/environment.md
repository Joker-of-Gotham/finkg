# 我的检索环境档案

> 这个文件记录**你这套环境**里有哪些数据表、字段和检索工具。
> 它是本地文件（应当 gitignore），不会进入 finkg 仓库——因为每个部署的数据平台都不一样，
> 而且这些是你机构的内部信息。
>
> 用法：第一次用 finkg 时花十几分钟做一轮探索把它建起来，之后每次发现新表就追加一行。
> agent 会在设计检索前用 `fg.py env` 读它，所以记得越准，取数越精确。

## 怎么把它填起来

让 LazySearch 帮你探索，然后把结果记到下面的表里：

```
先探索一下有哪些和「公司财务报表」相关的数据表，给出库名、表名和字段 schema
先探索一下有哪些和「股东持股」相关的数据表，给出库名、表名和字段 schema
先探索一下有哪些和「主营业务构成 / 分部数据」相关的数据表
先探索一下有哪些和「行情与估值」相关的数据表
列出你可以调用的全部检索工具，以及每个工具适合什么问题、需要哪些参数
```

关键在于：**每次取数时要求对方给出「用了哪张表、执行了什么 SQL」**，
`fg.py harvest show <id> --part provenance` 会把这些抽出来，照抄进下面即可。
